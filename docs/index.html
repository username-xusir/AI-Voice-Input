01 · 一按就说

把“打字”换成“说话”，
但不用改变你的工作流。

Voxa 不是另一个聊天窗口。它是一层贴着系统的输入法：出现在光标旁边，说完就消失。

H

接管 Win+H

低级键盘钩子拦截 Win+H，长按也只触发一次。Voxa 运行时，系统自带语音输入不会弹出。

↳

边说边写

实时预览直接写入当前输入框，按最长公共前缀只改变化的尾部，不会整段重打。

◷

静音自动结束

停止说话约 1.8 秒后自动收尾、最终校正并上屏。浮窗保持打开，点 × 或 Esc 才关闭。

Aa

自动标点

保留 Whisper 识别出的逗号、句号；不需要标点时一键关闭，中文英文都适用。

◐

三套独立主题

青色、白灰、炭黑三套完整配色，按钮和图标随主题切换，不混搭，不刺眼。

CPU

CPU / GPU 可选

默认 CPU 推理；设置里可切 GPU，后台重载模型，失败自动回到原设备。

02 · 底层原理

从按下 Win+H，
到文字出现在光标处。

整条链路都在本机完成：键盘钩子 → 麦克风 → VAD → 本地 ASR → 差异输入。

01 / HOOK

拦截快捷键

WH_KEYBOARD_LL 监听 Win+H，吞掉自动重复事件，防止系统原生语音输入抢走按键。

02 / CAPTURE

采集与判音

sounddevice 打开 16 kHz 单声道；RMS 能量门限 + Silero VAD 先挡住静音和环境噪声。

03 / PREVIEW

实时预览

每约 800 ms 把当前整段音频送进 whisper-base-int4-ov，得到稳定的预览文本。

04 / INSERT

差异上屏

计算新旧文本的最长公共前缀，只退格并补写变化的部分，用 Unicode SendInput 写进目标输入框。

05 / FINAL

最终校正

静音约 1.8 秒后，用 whisper-small（或 large）重跑最终结果，只修正差异；焦点丢失时回退剪贴板。

Win+H→Keyboard Hook→ Recorder→VAD→ OpenVINO ASR→Text diff→Input box

04 · 本地 vs 在线

为什么把语音输入
放回本地。

在线服务要上传、联网、订阅；Voxa 把这些全部收回本地，数据、延迟和成本都由你掌控。

什么时候本地更合适？

你在写私有文档、聊天、代码注释，或经常在没网/弱网环境工作；你不想为每分钟语音付费；你希望工具完全受自己控制。

  • 隐私敏感：会议记录、客户信息、未公开代码。
  • 离线场景：飞机、出差、内网、断网。
  • 长期成本：高频使用，不想按量付费。
  • 可玩性：换模型、改 UI、接自己的流程。

本地还给你：模型可换、热键可调、界面可改；每台机器都能独立运行，不被服务条款限制。
