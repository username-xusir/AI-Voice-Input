# Voxa 0.7.1

Windows 11 本地语音输入，接管 Win+H。完全离线，音频不上传。

## 安装

下载 `Voxa-Setup-0.7.1.exe`，双击安装。安装到当前用户目录，不需要管理员权限。

SHA256：`ae61ee8eb9cd18db0fee2bc7aab4017900ace8cbbeba1408bcbc613122b0d555`

安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”，选择“更多信息 → 仍要运行”。

安装包默认包含：

- Voxa 主程序（PyInstaller）
- OpenVINO GenAI CPU 运行时
- Whisper base int4 预览模型
- Whisper small int4 最终模型
- **OpenAI Whisper large-v3-turbo int4 高精度模型（默认勾选；性能弱的电脑可在组件页取消）**

从旧版 VoiceIn 升级时，安装器会停止旧进程、移除旧版自启动和快捷方式；旧配置自动迁移到 `%LOCALAPPDATA%\Voxa`。Voxa 每次启动也会清理遗留的 VoiceIn 进程，避免旧版小设置页和旧 Win+H 钩子同时存在。

## 使用

1. 在输入框按 **Win+H** 开始。
2. 说话；文字实时输入到当前输入框，麦克风按钮显示跟随音量的声波。
3. 停止说话约 1.8 秒，自动结束、自动校正、自动关闭。
4. 也可以按 Win+H / Esc 手动提前结束。
5. 托盘左键、浮窗“设置”，或再次双击桌面快捷方式，都会打开**同一个详细设置页**。
6. 首次手动启动 Voxa 也会直接打开设置；开机静默启动不会弹窗。

## 0.7.1 修复

- **三套主题完全独立**：
  - 青色：保持原来的青色/青绿配色不变。
  - 浅色：白色、浅灰、深灰文字；面板、按钮、开关、麦克风、关闭按钮全部白灰系。
  - 深色：炭黑、深灰、浅色文字；面板、按钮、开关、麦克风、关闭按钮全部炭黑系。
  - 不再出现浅色/深色里夹着青色按钮或青色开关的“嵌套配色”。
- **图标颜色随主题**：青色和浅色主题使用深色图标；深色主题使用浅色图标（麦克风声波、关闭 X、返回箭头、播放/暂停）。
- **修复鼠标移到 × 上按钮变黑**：Qt 的 `QColor` 不解析 CSS `rgba(...)` 字符串，旧代码把 hover 色当成了不透明黑色；现在自绘颜色会正确解析 RGB 和 alpha。
- **large 高精度模型默认打包**：安装器的 large 组件默认勾选；设置里的“高精度模型”明确标注 `OpenAI large-v3-turbo · 更慢`。
- **统一设置页**：浮窗“设置”、托盘左键、托盘菜单、桌面快捷方式、首次手动启动，全部打开同一套详细设置页；同时启动时清理旧 VoiceIn，避免再看到旧版小设置卡片。
- 设置页标题显示 `v0.7.1`，可据此区分旧版页面。

## 0.7.0 功能（继续保留）

- Voxa 更名；安装/数据目录、快捷方式、托盘、配置全部更新。
- 完整设置：自动标点、实时预览、自动上屏、高精度模型、CPU/GPU、语言、静音自动结束、静音时长、主题、开机自启动。
- 声波麦克风；静音自动结束 0.8–4.0 秒可调；自动标点可开关。
- CPU/GPU 热切换；失败自动保留原设备。
- 单实例激活：再次启动打开已有实例设置。

## 性能

- 预览 base：约 0.8–1.5 秒一次
- 默认最终 small：约 3–5 秒
- 高精度 large：CPU 约 10–20 秒，默认关闭，按需在设置里开启
- 启动：约 4–6 秒（默认只加载 small + base）
- CPU → GPU 热切换：约 10–15 秒重载模型（本机 Iris Xe）

## 已知限制

- 高精度 large 较慢，默认关闭。
- 实时输入依赖光标；录音时不要移动光标或改选区。
- 本机 Intel Iris Xe 核显用 OpenVINO GPU 反而更慢，默认 CPU；独显机器可自行切换。
- 极少数不接收 Unicode 字符的应用可能无法实时上屏。
- 安装包未签名，SmartScreen 可能提示未知发布者。
